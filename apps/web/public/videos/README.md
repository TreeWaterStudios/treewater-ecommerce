# Video Assets Directory

## Folder Purpose

This folder stores video files for the application. It is part of the public assets directory and is served statically by Vite during development and production.

## Usage Instructions

1. Place video files (.mp4, .webm, .mov, .avi, etc.) in this directory
2. Supported formats: MP4, WebM, MOV, AVI, and other common video formats
3. Keep file sizes reasonable for web delivery (consider compression for large files)
4. Use descriptive filenames (e.g., `hero-intro.mp4`, `product-demo.webm`)
